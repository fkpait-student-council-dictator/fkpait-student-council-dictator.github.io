# Студентська рада ФКПАІТ ОНТУ

Офіційна сторінка Cтудентської ради Відокремлений структурний підрозділ "Фаховий коледж промислової автоматики та інформаційних технологій Одеського національного технологічного університету" 

## Загальна інформація

- Голова Студентської ради (з 29.11.2024 до 12.12.2026) ГРИГОРАЩЕНКО Вячеслав.
